# HandyMan Do IT · Website

The bilingual (FR/EN) marketing site for [HandyMan Do IT](https://app.handymandoit.com), built with Next.js 16 + Payload CMS 3. It replaces the old handymandoit.com.

- Plan and specification: [docs/PLAN.md](docs/PLAN.md)
- Deployment (Hostinger + Neon + Cloudflare R2): [docs/DEPLOY.md](docs/DEPLOY.md)

## Requirements

- Node.js **24.22.1+** (or 22.23.4+)
- Docker (for the local Postgres)

## Getting started

```bash
cp .env.example .env          # then set PAYLOAD_SECRET
docker compose up -d          # Postgres 17 on :5432
npm install
npm run dev
```

- Site: http://localhost:3000 (redirects to `/fr` or `/en` based on the browser)
- CMS: http://localhost:3000/admin. The first account you create becomes admin.

## Scripts

| Script | What it does |
|---|---|
| `npm run dev` | Dev server |
| `npm run build` / `npm start` | Production build / server |
| `npm run start:prod` | Runs pending migrations, then starts (used on Hostinger) |
| `npm run typecheck` | TypeScript, no emit |
| `npm run lint` | ESLint |
| `npm run generate:types` | Regenerate `src/payload-types.ts` after schema changes |
| `npm run migrate:create` | Create a DB migration for production |

## Layout

```
src/
  app/(site)/[locale]/   public pages (next-intl, fr default)
  app/(payload)/         CMS admin + API (generated by Payload)
  collections/ globals/  CMS schema (localized fr/en)
  components/            UI
  i18n/                  routing (localized slugs), request config
  messages/              UI strings (fr.json, en.json)
  lib/                   shared helpers, site defaults
  proxy.ts               locale detection / redirects
```
